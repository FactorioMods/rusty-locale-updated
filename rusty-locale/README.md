# Rusty's Locale Utilities: Updated

A utility library for mods that need localized prototype names and descriptions or prototype icon definitions. It supports items, recipes and other prototype types.

This fork provides the library under a separate Factorio 2.1.24 mod ID. Install it when a dependent mod requires it.

Requires Factorio 2.1.24 or later. Disable `rusty-locale` before enabling this fork. Required content and optional integrations are listed in the mod dependencies.
